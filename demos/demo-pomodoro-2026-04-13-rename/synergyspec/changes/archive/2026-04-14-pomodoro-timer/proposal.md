## Why

Users need a simple, focused productivity tool to apply the Pomodoro Technique — alternating 25-minute work sessions with 5-minute rest breaks — without the distraction of feature-heavy alternatives. A lightweight React-based timer delivers this with minimal friction.

## What Changes

- Add a Pomodoro timer web app built with React
- Provide a 25-minute work countdown and 5-minute rest countdown
- Auto-transition between work and rest phases
- Start, pause, and reset controls
- Visual indication of current phase (work vs. rest)
- Audible or visual notification when a phase ends

## Capabilities

### New Capabilities
- `pomodoro-timer`: Core countdown timer supporting work (25 min) and rest (5 min) phases with start/pause/reset controls, phase auto-transition, and end-of-phase notification.
